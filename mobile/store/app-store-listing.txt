REVIEW NOTES
This app is a Capacitor WebView shell that loads our production site https://www.tabascomusic.com (Next.js on Vercel). It includes a native splash screen, status bar styling, Universal Links for song URLs, and Android/iOS deep links. Account features use Supabase Auth on the same origin. Demo: create an account with any email on the sign-in screen, or use the shared test credentials we provide in App Review Information if requested.
